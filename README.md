## 🧰 Run the App:

- To run the Backend locally:

Method 1: Via GUI

Open the project in your IDE (IntelliJ IDEA or VS Code).

Navigate to the backend folder and open the HCCapstoneBEApplication file.

Click the green Run button next to the main method.

Method 2: Via Terminal Commands

Start at the root repository directory (/HCLCapstone), then execute:

```shell
cd BE
./mvnw spring-boot:run
```

- To run the frontend locally:

Start at the root repository directory (/HCLCapstone), then execute:

```shell
cd FE
npm run dev
```
