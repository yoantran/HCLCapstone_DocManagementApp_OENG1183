Update my profile

Updates the currently logged-in user's name, phone number, and/or avatar image. All fields are optional — only provided fields will be updated.

Avatar rules:

  • Allowed formats: JPEG, PNG
  • Max file size: 10MB
  • Old avatar is automatically deleted from storage when a new one is uploaded
  • A signed URL (valid for 1 hour) is returned to view the new avatar

Available to both Staff and Boss.

Update a department

Updates a department. All fields are optional — only send what you want to change. Unset fields keep their current value.

Update name only: Send name field, omit managerId.

Replace manager: Send managerId with a valid manager user UUID. → Old manager's department is set to null automatically. → New manager is assigned to this department. → New manager must not already be manager of another department.

Remove manager (no manager assigned): Send managerId as empty string "" OR send removemanager: true. → Current manager's department is set to null. → Department's manager is set to null.

Add manager to a department that has no manager: Send managerId with a valid manager user UUID — same as replacing manager.

Authorizations:
bearerAuth

Soft delete a user

Soft deletes a user by setting isDeleted=true. The user record is NOT permanently removed.

If the deleted user is a manager:

  • Their department's manager is automatically set to null
  • The user's department assignment is cleared
  • No manual reassignment needed before deletion

Service Auth

Machine-to-machine token issuance for trusted services (e.g. malware-scan).

Issue a short-lived service token

Exchanges a service client_id + client_secret for a short-lived JWT service token. The returned token must be sent in the X-Service-Token header on calls to the document upload endpoints. Tokens expire (default 5 minutes); request a new one when the current token nears expiry.

This endpoint is for trusted backend services only, NOT for end users or browsers.

Request Body schema: application/json
required
clientId
string

Service client identifier

clientSecret
string

Service client secret (shared out-of-band)

Responses

Generated server url

Documents

Document upload and retrieval. STAFF and manager can upload/view own docs. manager can also view/delete department docs.

Upload a single document (via scan service)

Uploads one document file to the Supabase documents bucket. Automatically assigns it to the uploader's department. Triggers a WebSocket notification to the department manager. A signed URL (valid for 1 hour) is returned to view the document.

This endpoint is called by the trusted malware-scan service, NOT directly by the browser. The caller must send BOTH: • Authorization: Bearer — identifies the real uploader • X-Service-Token: — proves the request came through the scan service Obtain the service token from POST /auth/service-token.

Allowed formats: PDF, DOCX, CSV Max file size: 10MB
